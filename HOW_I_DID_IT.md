# How I Did It

I built this project using Node.js as a simple AI decision assistant for students.

## Process
1. Designed user inputs: interest, budget, location.
2. Added tool-calling functions for:
   - get_insights
   - query_knowledge
3. Combined tool outputs into recommendations.
4. Added reasoning output for explainability.
5. Added validation and error handling.

## Challenges
- Making outputs simple and useful
- Structuring explainable recommendations
- Improving robustness after evaluator feedback
