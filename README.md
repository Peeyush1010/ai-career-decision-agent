# AI Career & University Decision Agent

This project is an AI-based agent that helps students choose the best academic path based on their interests, budget, and preferred location.

---

## Features
- Career recommendations based on user input
- Budget-aware suggestions
- Explainable outputs using LPI tools

---

## Tech Stack
- Node.js
- LPI Sandbox

---

## How It Works
The agent takes user input (interest, budget, location) and processes it using structured logic.

It uses LPI tools:
- `get_insights` → for decision guidance
- `query_knowledge` → for structured information

The outputs are combined to generate clear and explainable recommendations.
