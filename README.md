# AI Career & University Decision Agent

This project is an AI-based agent that helps students choose the best academic path based on their interests, budget, and preferred location.

## Features
- Career recommendations based on user input
- Budget-aware suggestions
- Explainable outputs using LPI tools

## Tech Stack
- Node.js
- LPI Sandbox

## How It Works
The agent takes user input and uses structured logic along with LPI tools (`get_insights`, `query_knowledge`) to generate recommendations.

## Run the Project
```bash
node agent.js

## Example Output
The agent provides:
- Recommended academic path
- Suggested countries based on budget and preference
- Actionable next steps for students
- Sources used (LPI tools: get_insights, query_knowledge)
